## time: 2026-11-18 | role: developer-tooling-engineer

### 变更内容

- 用户要求：为 VibeDoc 增加给人看的文档与代码浏览器、给 AI 的缩略索引，并做到"改了一处自动标注过期"，把流程固定为 需求列表 → AI 写代码 → 标记需求完成并更新行为文档与函数级注释 → 更新总览文件。缩略索引的字段名用单 token 的英文单词，不用 AOCI 式的单字母。
- 新增 `index/`：`vibedoc index generate|stale|ack|show|check`。每个源文件一行索引（`role`/`note` 由 AI 写，`uses`/`api`/`reads`/`writes`/`defines` 按代码生成），`INDEX.txt` 为全项目总览。
- 新增过期账本 `<index.dir>/ledger.json`：函数注释对应函数体哈希、索引行对应文件哈希、行为与契约文档小节对应 `<!-- refs: ... -->` 中每个对象的哈希；对象变了而描述没变即过期，引用对象不存在报失效引用。
- `features set done` 与 `rules mark` 增加完成门禁（`index.gate`，默认开）：实现函数注释、索引行、引用该条目的行为文档小节都必须是最新的，否则拒绝并列出清单；`--skip "原因"` 放行并记账。通过后自动刷新索引与总览。`features set` 支持 `--impl`。
- 看板新增「文档浏览」标签页：按模块的文件职责列表、带行号的源码与函数列表、需求 → 实现函数 → 行为文档小节的串联视图、过期汇总；Markdown 渲染隐藏整行 HTML 注释。
- AGENTS 规则模板在启用 `index` 时写入索引用法与完成链路。

### 影响范围

- 只有配置了 `codemap` 和 `index` 的项目受影响；未配置的项目命令、看板与规则区块不变。
- 新接口：`GET /api/p/<id>/index`、`GET /api/p/<id>/index/file?path=`（只返回索引里的源码文件）。

### 文档

- README 增加「AI 索引与过期检测」、配置字段、命令与文件说明。

### 验证

- 在 HCONet（976 个文件、3475 个函数）上生成索引约 1 秒；内置浏览器中检查了文档浏览页的模块列表、源码视图、需求与文档视图、行为文档小节抽屉和实时刷新。
