# 人类区

这里放**你亲自提出的东西**和**等你拍板的东西**。其余文档是 AI 维护的实现契约与历史记录，入口见 `{{docs.root}}/README.md`。

| 路径 | 内容 | 谁写 | AI 可以做什么 |
| --- | --- | --- | --- |
| `{{docs.sketches}}/` | UI 手绘草图、截图标注 | 你 | 只读；按草图实现时在正式文档注明依据的原图，不覆盖原图 |
| `{{docs.requests}}/` | 需求原话、想法、优先级说明 | 你 | 只读；落实后在正式文档引用，不改写原文 |
| `{{rulesDir}}/` | 你的逻辑规则，按模块 × 前端/API/后端/数据库，带实现状态 | 你（看板或编辑器） | 只能用 `vibedoc rules` 改状态行；你要求时才执行 |
| `{{docs.questions}}` | 等你决策的产品／行为问题 | AI 提问，你回答 | 新增问题；你答复后把结论写入行为文档并删除该条 |
| `{{docs.deliverables}}/` | 给人读的交付说明（用户手册、技术概览） | AI | 按你的要求更新 |

## 放置约定

- 草图按页面或功能分子目录，文件名写清页面和版本，例如 `settings/profile 2.png`。
- 需求原话一个主题一个文件，例如 `sharing.md`；只写口语即可，不需要格式。
